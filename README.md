# Polymathic Projects

Personal project blog for Gregory Whitmore — data analytics, 3D printing/design, and creative coding, built with Jekyll and the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme and hosted on GitHub Pages at [creativepolymath.github.io](https://creativepolymath.github.io/).

## What's here

Write-ups on data analysis projects (Python/R visualizations, Kaggle work), parametric 3D design, and other build-in-public experiments — plus links to my [resume](https://creativepolymath.github.io/), [Medium](https://medium.com/@gwhitmore), and [Kaggle](https://www.kaggle.com/gregwhitmore) profiles.

## 🇲🇽 Mexico, Jan 1 – Mar 31, 2027

Starting January 1, 2027, I'm spending 90 days living and working remotely in Mexico. The blog is shifting to cover that chapter as a digital-nomad travel journal alongside the usual project posts — daily/weekly dispatches on where I am, what I'm working on remotely, and what I'm learning along the way. Expect a new post category for trip entries once it kicks off.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Site config lives in [`_config.yml`](_config.yml); posts are in [`_posts/`](_posts); standalone pages (About, archives) are in [`_pages/`](_pages).

## Troubleshooting

If you hit a Jekyll issue, check the [Jekyll Forum](https://talk.jekyllrb.com/) or [Setting up a Jekyll site with GitHub Pages](https://jekyllrb.com/docs/github-pages/).
